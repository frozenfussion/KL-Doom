# OpenStreetMap snapshots

`klcc.osm` - KLCC area, Kuala Lumpur. Bounding box (W,S,E,N): 101.7080, 3.1543, 101.7152, 3.1615 (about 800 m x 800 m).
Downloaded on 2026-10-08 from the OSM API with `scripts/fetch-osm.sh`.

Contains the Petronas Twin Towers (modelled as stacked `building:part` ways, up to 452 m),
Menara 3 Petronas, Suria KLCC, KLCC Park and the surrounding streets.
